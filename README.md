A low-latency voice assistant that transcribes speech, searches for current information, and speaks back in Arabic, English, and Malayalam.

**Stack** · Python · Azure OpenAI Realtime · Azure Speech

**Stack** · FastAPI · Next.js · Azure Blob Storage

### [Therapy Scheduler](https://github.com/gokul6040/Google-OR-Scheduler)

**Stack** · Python · Google OR-Tools · PostgreSQL
